# Périmètre des archives

Cette extension est livrée en sources Godot 4.3. Les exécutables Windows/APK 0.2.0 sont **anciens** et n'intègrent pas les dix mondes. Ils ne sont pas redistribués avec cette extension ; les anciens SHA du lot 2 restent des traces historiques, pas ceux de la nouvelle livraison.

L'archive source originale du lot 2 est conservée à la racine et le rendu initial est figé dans `docs/rendu/reference/`, commit `370900f`. La nouvelle archive source et son SHA sont indiqués dans le message de livraison. Les sources courantes restent dans `skate_game/`.
